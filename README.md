# Unmixing highly mixed grain size distribution data via maximum volume constrained end member analysis
This project is for Unmixing highly mixed grain size distribution data via maximum volume constrained end member analysis.

## Configuration instructions
The project structure distinguishes two kinds of folders:
- lbaemma folder includes R code for EMMA.
- nmf folder includes MATLAB code for APFGM and the results from EMMA and APFGM.

## Installation instructions
- library(renv) init() is used to obtain renv.lock file. By looking at this file: This code is run by R version 4.2.3.
- Matlab R2024b

## Operating instructions
Please see Readme file in lbaemma folder and nmf folder.
